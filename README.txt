# 图片转矢量 SVG（桌面版源码）

一个把图片转成矢量 SVG 的本地工具，支持三种模式：
- 线条 · 可调粗细：把线条/文字抽成连续单线，导出描边路径，可在 AI(Illustrator) 里调线宽。
- 实心 · 轮廓+填充：先描边再填充，能正确做孔洞。
- 彩色 / 彩色·精细：颜色量化后逐色填充。

## 运行（推荐）
直接双击  启动图片转矢量SVG.bat  即可打开界面。
依赖已全部放在本文件夹的 libs 目录里，无需再安装，可直接把这个文件夹拷走用。

## 运行（手动命令行）
在本文件夹里运行：
   python run.py

## 说明
- 完全本地处理，图片不上传。
- “锐化”可改善模糊图片边缘。
- 源码结构：
  image_to_svg_app.py  —— 界面与交互
  vectorizer.py        —— 矢量化算法（骨架描边 + 轮廓填充）
